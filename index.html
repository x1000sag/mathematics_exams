Эта заглушка отдаётся только при публикации Deploy from a branch (корень репозитория). Рабочий сайт — однофайловая сборка из workflow «Сборка и GitHub Pages».

В репозитории: Settings → Pages → Build and deployment → Source выберите GitHub Actions, затем перезапустите workflow или сделайте push в main.

Артефакт для офлайн: job «build» → скачать kr-integraly-single.
