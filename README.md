# Контрольная: криволинейные и поверхностные интегралы

Конспект к переписыванию образца. Внутри все четыре варианта с подробными решениями, шпаргалка формул, алгоритмы по типам задач и список мест, где в этих листах обычно теряют знак.

Варианты 2–4 устроены одинаково: масса кривой, поверхностный интеграл I рода, ещё один интеграл I рода, криволинейный интеграл II рода, потенциал, поток. Вариант 1 — смешанный лист с двойными интегралами.

## Как открыть

```bash
npm install
npm run dev
```

Сервер разработки поднимается на порту 4179. Сборка:

```bash
npm run build
npm run preview
```

## Как пользоваться

- Слева содержание. Поиск ищет и по тексту решений.
- «Режим тренировки» прячет решения и сводку ответов.
- «Лента» показывает весь конспект подряд.
- Галочка «разобрал» запоминается в браузере.
